# College Discovery Platform

A full-stack College Discovery Platform built using React.js, Node.js, Express.js, and MongoDB.

## Features

- College listing
- Search colleges
- Filter by location
- Sort colleges
- Pagination
- View college details
- Compare colleges
- MongoDB database integration
- REST API integration
- Responsive UI

## Tech Stack

Frontend:
- React.js
- CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

### Backend
